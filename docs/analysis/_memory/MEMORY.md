# Domain Glossary

- **meeting transcript**: A text file containing the spoken content of a meeting, typically auto-generated by speech-to-text tools. Not produced by this system in v1. Input format: plain text (.txt). Language: mixed English and Turkish, auto-detected.
- **topic cluster**: A group of transcript segments related to the same subject. The system identifies these and produces 1-2 sentence summaries.
- **action item**: A task or commitment identified from the transcript that is assigned to someone or scheduled for a future date. Extracted with assignee and deadline when mentioned; unspecified fields marked as "unspecified."
- **output document**: The structured analysis result, formatted in Markdown (MUST). PDF (SHOULD, deferred to later version).
- **uncertain finding**: A topic, summary, or action item that the LLM could not identify with sufficient confidence; flagged for manual review.
- **language detection**: Automatic detection of the primary language (English or Turkish) of an input transcript; implicit in-scope capability (added 2025-09-17, C-002 resolution).

# Stakeholders

- **Internal team members** — Primary users. Upload transcripts, review analysis output, act on action items.
